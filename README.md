# DevPulse

DevPulse is a developer activity dashboard for tracking coding activity, repository trends, and development habits in one place.

## Goals

- Collect repository and contribution activity
- Summarize recent development trends
- Track languages and project activity over time
- Provide a clean dashboard for exploring developer metrics

## Planned Stack

- React
- Python / FastAPI
- PostgreSQL
- Docker
- GitHub Actions

## Status

DevPulse is under active development. The first milestone focuses on establishing the backend API and project structure before adding data collection and dashboard features.
